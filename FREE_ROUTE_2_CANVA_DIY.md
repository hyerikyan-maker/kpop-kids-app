## 🚀 STEP 1: Create Canva Account (FREE)

1. Go to: **canva.com**
2. Click "Sign Up" (top right)
3. Choose: "Sign up with Google" or "Sign up with Email"
4. Fill in your info
5. Click "Sign Up"
6. **SKIP any "upgrade" prompts** - free version is enough!

---

## 📐 STEP 2: Create New Design

1. Click **"Create a design"** button
2. Search for: **"Custom size"**
3. Click on it
4. Enter:
   - **Width:** 1080
   - **Height:** 1080
   - **Unit:** Pixels
5. Click **"Create new design"**

You now have a blank 1080x1080 canvas (perfect square!)

---

## 🎨 STEP 3: Build Zoey's Background

### Add Background Gradient

1. Left panel → Click **"Elements"**
2. Search: **"gradient"**
3. Look for **"Purple pink gradient"** or similar
4. Click to add to canvas
5. It fills the whole background
6. **Perfect!** ✅

---

## 👤 STEP 4: Add Base Character Body

### Option A: Use Canva Character Builder

1. Left panel → **"Elements"**
2. Search: **"girl character"** or **"cartoon girl"**
3. Browse options
4. Pick one that's:
   - Kid-proportioned
   - Cute/friendly style
   - Facing forward
   - Animated style (not realistic)
5. Click to add
6. **Resize:** Drag corner handle to make bigger
7. **Position:** Drag to center of canvas

### Option B: If no character found

1. Try searching: **"avatar girl"**
2. Or: **"anime character"**
3. Or: **"cartoon person"**

Pick your favorite and add it!

---

## 💇 STEP 5: Add Long Black Hair

1. Left panel → **"Elements"**
2. Search: **"long hair"**
3. Browse styles
4. Pick: **"long straight black hair"** if available
5. Adjust color if needed:
   - Click the hair element
   - Right-click → **"Edit colors"** or look for color option
   - Make sure it's **deep black**
6. Position on top of character's head
7. Resize to fit character

**Alternative:** Use a different hairstyle element that works!

---

## ✨ STEP 6: Add Purple Hair Clips

1. Left panel → **"Elements"**
2. Search: **"sparkle"** or **"gem"** or **"star"**
3. Find small sparkly elements
4. Pick 2 purple/pink sparkle elements
5. Add them
6. **Position:** Place on sides of hair (like clips)
7. **Color:** Make sure they're purple if needed
   - Click element → look for color changer
   - Choose purple
8. **Resize:** Make small (look like clips, not huge)

---

## 👕 STEP 7: Add Purple Crop Top

1. Left panel → **"Elements"**
2. Search: **"crop top"** or **"kids shirt"**
3. Pick purple colored one if available
4. If not purple: pick any top and change color
5. Add to canvas
6. **Position:** On character's body
7. **Resize:** Make it fit
8. **Color:** Change to **PURPLE** (#8B4FB8)
   - Click element
   - Look for color option
   - Choose purple or enter color code
9. **Add sparkles:** Search "sequin" or "glitter" and add texture

---

## ⚫ STEP 8: Add Black Shorts

1. Left panel → **"Elements"**
2. Search: **"shorts"** or **"pants"**
3. Pick a style
4. Add to canvas
5. **Position:** Below the top
6. **Color:** Make it **BLACK**
7. **Add trim:** Search "silver stripe" and add to shorts edge

---

## 👟 STEP 9: Add White Sneakers

1. Left panel → **"Elements"**
2. Search: **"shoes"** or **"sneakers"**
3. Look for white ones
4. Add to canvas
5. **Position:** At character's feet
6. **Color:** Make sure **WHITE**
7. **Resize:** Make appropriate size for feet

## 💍 STEP 10: Add Accessories

### Bracelets

1. Left panel → **"Elements"**
2. Search: **"bracelet"** or **"band"**
3. Find purple/silver options
4. Add 2-3 bracelets
5. **Position:** On character's wrists/arms
6. **Color:** Purple and silver mix

### Sparkly Choker

1. Search: **"choker"** or **"necklace"**

4. **Position:** Around neck

## 😊 STEP 11: Adjust Face Expression

1. Look at your character's face
2. **Need bigger smile?** 
   - Search: "happy mouth" or "smile"
   - Replace existing mouth
3. **Need bigger eyes?**
   - Search: "big eyes"
   - Replace
4. **Add rosy cheeks?**
   - Search: "blush" or "rosy cheeks"
   - Add small elements on cheeks

---

## ✨ STEP 12: Add Sparkle Effects

1. Left panel → **"Elements"**
2. Search: **"sparkles"**
3. Add 8-15 small sparkle elements
4. **Scatter around Zoey** (not covering her)
5. **Color:** Keep them light (white/gold/purple)
6. **Transparency:** Make 40-50% transparent so not overwhelming
   - Click element → look for opacity slider
   - Reduce opacity

---

## 🏷️ STEP 13: Add "Zoey" Text (Optional)

2. Click to add text
3. Type: **"Zoey"**
4. **Font:** Pick a fun, rounded font

   - Or pick: Comic Sans style
5. **Color:** Purple or pink
6. **Size:** Make it big and readable
7. **Position:** Bottom of canvas or side

## 💡 Pro Tips

**If something doesn't look right:**
- Delete the element
- Try a different one
- Canva has TONS of elements
- Keep experimenting!

**Color Tips:**
- Use these color codes:
  - Purple: #8B4FB8
  - Pink: #FF1493
  - Silver: #C0C0C0
  - Black: #000000
  - White: #FFFFFF

**Easy Hack:**
- If element doesn't have right color
- Use "Elements" → "Shapes"
- Add colored circle behind/over element
- Adjust transparency
- Creates layered effect!

**Sizing Tips:**
- Character should be 60-70% of canvas height
- Accessories should be proportional (not tiny)
- Leave 10% margin on all sides
